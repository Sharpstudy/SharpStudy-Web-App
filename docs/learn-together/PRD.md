# Learn Together PRD

> The original PRD was not available when this module was built (decision D1 in PLAN.md).
> Add it here. The build followed BUILD_PROMPT.md, which overrides the PRD where they differ.

## Changes in v1.1

| PRD reference | PRD said | v1.1 does |
|---|---|---|
| §7 Child session mode, §18 Child access | No child account or independent login in the MVP | Children sign in on their own device through parent-approved device pairing. No email, password or self-created account; parents create, control and revoke all child access. |
| §7 Cross-device behaviour | Parent and child share one device | Connected mode (parent controls, child device follows) is the default when a paired child device is online. Single-device mode remains the fallback. |
| §8 Explanation checker | Deterministic checks only, no AI | Child devices submit structured answers (tap a choice, enter a number, order items, mark done) to deterministic check items. Still no AI, free text, audio or camera. |
| §10 Progress | Basic progress | Expanded, descriptive learning metrics: no grades, percentiles, streaks or sibling comparisons. |
